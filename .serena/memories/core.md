Hermes Agent is a managed full-stack React/Vite + Express/tRPC application at /home/ubuntu/hermes-agent. Frontend source is under client/src; backend procedures are in server/routers.ts and persistence helpers in server/db.ts; Drizzle schema and migrations are under drizzle/. Owner-only control is enforced in Hermes procedures by comparing the authenticated user openId to ENV.ownerOpenId. DashboardLayout is the shared authenticated shell; Home.tsx renders the operator sections. Database schema changes must be generated with drizzle-kit and applied through the managed SQL workflow. Realtime UI uses short refetch intervals rather than an always-on process.
